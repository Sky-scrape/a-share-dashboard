## 一、一句话现状

**我们用日线 + 换手 + 人气 + 龙虎榜 + 竞价，在 2026-07~10 月上做了 7 轮实验，

| 轮次 | 试了什么 | 结果 |

| C16 | 涨停池 + 9 类情绪结构特征，穷举 126 个组合 | 训练段为正 **0 个** |
| C17 | 形态（K线/均线/影线/缺口）+ 量价 + 筹码近似 + 人气榜 + 龙虎榜，40 特征 | 139 桶，四判据全过 **0 个** |
| C17b | 真实换手率/流通市值/筹码交换度（补了股本），8 特征 | 35 桶 **0 个**；组合最好 −0.12% |
| C18 | 小市值池 44 特征 155 桶 + 止盈止损网格 + 横截面 Top3/5/10 | 全部 0 通过；**止盈止损是负贡献** |
| C19 | 涨停统计做择时 + 竞价信号 | 涨停统计无效（r<0.16）；竞价抢筹有效（负向） |

**明确否掉的方案：**
- ❌ 止盈止损：基准 −0.14% → 加止损 −0.22~−0.39%。小盘股日内波动大，止损被反复打，
  把会回来的单锁死在亏损位。**这套票只能老实持有到收盘。**
- ❌ 用封板率/炸板率/连板晋级率做择时闸门：与次日收益相关性 r = −0.11~+0.16，分档不单调。
- ❌ 把负面清单套到 C7 生产池：505 笔 +2.45% → 排除后 +2.46%，完全无效。
  原因：C7 涨停组本来就是高涨幅/高量比/大成交额，**这些在涨停票池里是入选理由不是风险信号**。
- ❌ 收紧买点窗（5%→3%）：净均从 +0.72% 掉到 +0.30%，样本减半。
- ❌ 抬高 min_score 救胜率：85+ 分档 T+2 也只有 −0.50%，分数和可执行收益不相关。

## 五、方法论纪律（这几条是用真实错误换来的，务必遵守）

### 1. 涨停封板会伪造出完美信号（最贵的一课）

我们曾在「收盘创 60 日新高 + 缩量 + 小成交额」上做出 **+4.02%、胜率 70%、日级 t=+8.02、
四个月逐月全正** 的策略。看起来可以上线。

抽查发现：237 笔里 **120 笔（50.6%）T+1 直接涨停**，收益中位数 **+9.76%**，
1354 笔"创新高"里 **85% 是 T 日涨停**。

真相：**「缩量创新高」=「T 日涨停封板」**——封板后无成交所以缩量，次日一字板所以跳空。
这些票 **T 日收盘买不进（封单排队）、T+1 开盘卖不出（一字板）**。

加两条硬约束后（`T 日涨幅<9.5%` 且 `T+1 开盘<9.5%`），策略从 +4.02%/t=8.02 → **−0.15%/t=0.0**。

**识别特征**：收益中位数贴着 +9.8%、隔夜跳空异常大、成交额极小、样本集中在少数票。
**只要看到收益中位数接近 +9.8%，立刻去查涨停比例。**

### 2. 前视偏差（第二课）

我们曾算出「T 日收盘买 → T+1 卖」有 **+0.335%、日级 t=+15.5**。那是假的——
样本上加了「T+1 开盘涨 0~5%」的筛选，而 T 日下单时不可能知道次日开盘区间。
去掉筛选后同一模式 **−0.342%**，差 0.68pp 全部来自那个条件。

**任何"按次日表现筛样本再回看当日收益"的回测，数字都是假的。**

### 3. 训练段有效 ≠ 有效

反复出现的模式：**训练段（7-8 月）+0.7%，验证段（9-10 月）−0.2%**。
典型例子：grade=3 竞价信号（训 +0.70% → 测 −0.17%）、竞价额占比高（+0.66% → −0.31%）、
低换手 Top3（+0.46% → −0.59%）。

**判据必须两条同时满足：训练段 Δ>0.3~0.4pp 且 验证段同向**。只满足一条的一律不上线。

### 4. 统计显著性的门槛

单笔标准差约 6.2%。要把 +0.5%/笔 做到 95% 置信、80% 检验力，**需要 n≈550 笔**。
7-10 月只有 87 笔可成交样本——**这个样本量下任何"提升 0.3pp"的结论都是噪声**。
必须用日级聚合 t 检验（消除同日相关性），不要用逐笔 t。

## 七、未完成事项（按优先级）

### P0 — 只有你们能做：验证「谁在买」

**主力资金流**（`/api/a-share/capital-flow/historical`）：
四类单子（超大单/大单/中单/小单）的流入/流出金额，日级历史回溯 1 年。
我们这边调用返回 `code=2004`（客户端专用），拿不到。

这是**唯一还没试过的维度**。前面所有实验都在价格和成交量的派生量里打转，
没有一项触及"资金主体"。建议验证：

1. **超大单净流入（前一日/T 日）能否预测 T+1 收益**——按净流入占成交额比分档
2. **超大单净流入 × 小市值** 交叉：小盘股里大单进场的信号是否更强
3. **主力净流入 vs 散户净流入（小单）背离**：主力买、散户卖的组合
4. 与已有的负向因子交叉：**竞价抢筹 + 超大单净流出** 是否比单一信号更强

### P0 — 同花顺筹码形态

`/api/a-share/special-data/chip-shape-stocks`：按四种形态筛选（双峰、高位密集、
低位密集、低位锁定）。同样锁在客户端。

我们的筹码是日线近似的（VWAP + 套牢盘比例），粗糙。官方形态分类如果能用，
建议直接测：**「低位密集 + 低换手」**、**「低位锁定」** 这两个形态的次日/三日收益。

### P1 — 高频分时（判断封板强度与承接）

`/api/a-share/high-frequency`。日线只能看开盘/收盘/最高/最低，看不到：
- 涨停封单的变化过程（封住→打开→回封）
- 尾盘 30 分钟的承接
- 大单成交的时间分布

这三样直接决定"次日能不能买、买了会不会被砸"。如果能拿到，建议做
**尾盘承接强度** 与次日开盘幅度的关系。

### P1 — 用 11-12 月数据做真样本外

我们所有结论都是在 7-10 月同一窗口里反复切分得出的，**这不是真正的样本外**。
11-12 月数据出来后，验证两件事：
- 「小市值 + 负面清单」（7-8 月 +0.42%/笔，t=1.11）在全新样本上是否还成立
- 隔夜漂移是否回到 0 附近（如果回到正，整套逻辑要重估）

### P2 — 把「竞价抢筹不买」接进生产

规则只有一句：**今天竞价被标「抢筹」的票，收盘不买。**
两段验证过（7-8 月 −0.10% / 9-10 月 −0.85%，n=817），成本是一天一次 API 调用。
它不会让策略赚钱，但能避免在情绪最热的票上接盘。

### P2 — 准入闸门（方案已被否，需要新思路）

我们原本想用「封板率/炸板率」做择时（判断今天该不该做），实测相关性 r<0.16、分档不单调，
**这个方案作废**。但目前仍然缺一个"什么时候不该做"的判据。
如果你们有市场层面的资金数据（全市场主力净流入、ETF 申赎），这是值得试的方向。
