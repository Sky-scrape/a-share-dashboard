# 最终筛选方案（主板口径 · M_Final）

> 迭代记录：M1 → M2 → M3 共 3 轮完整区间迭代（2026-01-05 ~ 2026-09-02 选股日，T+1 至 2026-09-03 验证，162 个选股日），3 轮内满足稳定标准收敛，M3 固化为 M_Final。选股范围（用户确认）：**仅沪深主板**（沪 600/601/603/605、深 000/001/002/003），创业板/科创板/北交所不入选；研究层（市场情绪/题材计数/板块涨停数/龙虎榜识别度）使用全市场数据。数据源：hithink-finance（本地 DuckDB 前复权+未复权双口径日线、涨停池历史含封单额/涨停时间/连板数/涨停原因、龙虎榜历史、同花顺行业指数目录/成分/日线、七大指数日线）。严格无未来函数：T 日选股仅用 ≤T 数据，T+1 数据仅用于验证。
> 近似说明：个股行业归属使用当前成分表（存在区间内成分漂移）；ST 状态以最新名称与涨停池 is_st 字段近似；次新股以数据窗口内首次出现日期近似。
> 本方案仅作复盘研究，不构成投资建议。

## 一、核心选股思想

- **主板双轮驱动**：涨停组做「强势股次日溢价接力」——主板涨停制度 10cm 下的连板梯队健康度、封板时间与封单质量是次日溢价的核心来源（M3 实测：涨停时间因子与连板数 corr 分别最强，09:45 前封板组均次 +3.14%，3 板以上组 +4.7~+5.1%）。
- **非涨停组做「活跃板块缩量回调低吸」**——规避贴 60 日高点追高（M1 实测 ≥0.99 桶 -1.35%）与深跌接飞刀（M2 实测 <0.86 桶 -0.30%）两端，取 0.86~0.95 回撤甜区 + 缩量（量比 ≤1.2）+ 板块当日活跃 + 流动性门槛（成交 ≥10 亿）。
- **市场环境闸门优先于个股选择**：四档环境（aggressive/normal/defensive/freeze）决定配额，aggressive 只做涨停组（非涨停组连续两轮负期望），冰点只观察不凑数。
- **买点与选股分离**：所有标的必须给次日观察条件；买点未触发不算选股失败（M3 实测：触发买点的标的 +5.91%/+5.00%，未触发的 +1.64%/-2.91%——纪律的价值大于预测）。

## 二、每日选股结构

```text
每日选出标的（按环境分档，不足额诚实说明原因、不凑数）：
- aggressive（进攻）：涨停组 2 只，非涨停组 0 只
- normal（正常）：涨停组 2 只，非涨停组 2 只
- defensive（防守）：涨停组 2 只，非涨停组 1 只
- freeze（冰点）：涨停组 0 只，非涨停组 ≤1 只（观察模式）
```

环境判定口径（每日盘后，全市场数据）：涨停家数 lu、上涨占比 adv、跌停家数 ld、上证 5 日涨跌幅、连板高度变化。
- aggressive：lu ≥ 75 且 adv ≥ 0.52 且 ld ≤ 15；
- freeze：lu < 25 且 adv < 0.30；
- defensive：lu < 45 或 adv < 0.40，或 ld ≥ 30（恐慌闸门）；
- 其余为 normal；昨日连板高度 ≥5 且今日骤降 ≥2 时，aggressive 降级为 normal（高位崩塌保护）。
- 区间实测环境分布：defensive 78 日 / normal 44 日 / aggressive 40 日；未出现 freeze 日（阈值作为保护性闸门保留）。

## 三、市场环境过滤

### 1. 适合积极选股的环境
- normal：涨停家数与赚钱效应中性偏上、有明确主线时，双组满配。

### 2. 需要降低仓位的环境
- defensive：涨停 <45 家或上涨占比 <0.40 或跌停 ≥30 家——只做涨停组 2 只 + 非涨停组 1 只，且涨停组优先早封板/高封单比标的。

### 3. 需要停止选股或只观察的环境
- freeze：涨停 <25 家且上涨占比 <0.30——不选涨停组，非涨停组最多 1 只或空仓观察。
- aggressive 环境对非涨停组是负期望环境（连续两轮实测 -0.51%/-0.47%）：该环境只做涨停组，不做低吸。

## 四、涨停组筛选规则

### 1. 市场环境要求
- aggressive/normal/defensive 均可选（defensive 降配额后由评分自然取优）；freeze 不选。

### 2. 板块选择标准
- 题材内涨停 ≥2 家（独狼板不选；题材热度计数用全市场口径）。
- 题材因子权重 15 分：同题材涨停家数 2→6 家线性给分（实测家数本身与次日表现梯度弱，作门槛与辅助更合适）。

### 3. 个股选择标准（总分 100，门槛 ≥55）
- **板块梯队 ladder 20 分**：1 板 0.55 / 2 板 0.9 / 3 板 1.0 / ≥4 板 1.0（≥4 板溢价两轮实测同向，小样本持续观察）。
- **涨停时间 time 20 分**：09:45 前 1.0 / 10:30 前 0.85 / 11:30 前 0.7 / 13:30 前 0.5 / 14:30 前 0.3（时间因子全场最强）。
- **封单质量 seal 20 分**：封单额/成交额 ≥15% 1.0 / ≥8% 0.7 / ≥3% 0.4 / <3% 0.15（8~15% 档实测 win 74% 最优）。
- **题材呼应 theme 15 分**：同题材涨停家数（见上）。
- **涨停结构 struct 15 分**：量比 0.8~3.0 1.0 / 3~4 0.7 / <0.8 0.6 / >4 0.45；≥4 板且题材 ≤2 家的独狼高位加速再打 5 折。
- **资金承接 liq 10 分**：成交 3~100 亿 1.0 / ≥1.5 亿 0.6 / 其余 0.3。
- 硬条件：成交 ≥1.5 亿、上市 ≥60 根 bar、涨停时间 ≤14:45（尾盘偷袭不选）。

### 4. 买点确认标准（T+1 执行层）
- 观察窗口：开盘涨幅 0 ~ +5%（低开不接，实测低开组 -0.91%）。
- 买点触发：开盘 ≤+5% 且盘中不破昨收 -3% 且收盘收阳。
- 高开 >+5% 一律放弃（情绪兑现区）。

### 5. 风险控制标准
- 风险位：盘中回撤 ≤-5% 或收盘 ≤-4% 即离场观察。
- 重点防范：高位情绪兑现（高开 ≥3% 后回落 3pct 以上归因为「情绪兑现」）、炸板断板、昨日一字板后的接力失败（昨日一字板直接不选）。

## 五、非涨停组筛选规则

### 1. 市场环境要求
- 仅 normal（2 只）与 defensive（1 只）环境选；aggressive/freeze 不选。

### 2. 板块选择标准
- 板块当日活跃：同花顺一级口径板块当日涨幅分位 ≥0.6 或当日有涨停；板块因子 25 分 = 0.55×当日涨幅分位 + 0.25×5 日分位 + 0.2×min(板块涨停家数/2, 1)。
- 实测板块涨停家数 ≥3 家的过热板块无溢价（-0.23%），家数分量降权。

### 3. 个股选择标准（总分 100，门槛 ≥55）
- **技术位置 pos 25 分**：距 60 日高点 <0.85 → 1.0 / 0.85~0.90 → 0.85 / 0.90~0.95 → 0.6（回调低吸甜区，追高与接飞刀两端规避）。
- **板块强度 sector 25 分**（见上）。
- **趋势结构 trend 20 分**：收盘 >MA20 >MA60×0.995 且 MA20 上行（基础 0.8），收盘 >MA10 加满 1.0。
- **辨识度 recog 10 分**：近 5 日龙虎榜净买 >0 1.0 / 板块内 ret20 第一 0.85 / 板块涨停 ≥2 家 0.6 / 其余 0.3。
- **动量 mom 10 分**：20 日涨幅 5~30% 1.0 / 0~5 或 30~40% 0.7 / 其余 0.4。
- **流动性 liq 10 分**：成交 5~80 亿 1.0 / 其余 0.6。
- 硬条件：成交 ≥10 亿且 5 日均额 ≥3 亿、上市 ≥120 根 bar、当日涨幅 -3~+7%、20 日涨幅 0~30%、距 60 日高点 0.86~0.95、量比 0.35~1.2（缩量）、非当日涨停/跌停、同板块分散（默认不同板块优先）。

### 4. 买点确认标准（T+1 执行层）
- 观察窗口：开盘 -2% ~ +3%。
- 买点触发：开盘 ≥-2% 且收盘站上 max(开盘价, 昨收)。
- 实测触发组 +5.00% vs 未触发组 -2.91%：未触发坚决不进。

### 5. 风险控制标准
- 风险位：盘中 ≤-4% 或收盘 ≤-3.5% 即离场。
- 重点防范：板块退潮补跌（板块当日跌幅 ≤-0.5% 时个股收红概率显著下降）、资金承接不足（T+1 成交缩量 <0.55 倍且收跌）、持续阴跌。

## 六、共同规避规则

### 1. 禁止选择板块
- 无当日涨停且 5 日分位 <0.6 的冷门板块；板块涨停 ≥3 家的过热一致板块（低吸端）。

### 2. 禁止选择个股类型
- 范围外：创业板（300/301）、科创板（688/689）、北交所、B 股。
- ST/*ST、次新股（数据窗口内首次出现不足 60/120 根 bar）、昨日一字板（涨停组）、尾盘偷袭板（14:45 后）、独狼板（题材内涨停 <2 家）、当日涨停或跌停股（低吸端）。
- 流动性不达标：涨停组 <1.5 亿、低吸组 <10 亿。

### 3. 应放弃买点的情况
- 涨停组：低开（<0）、高开 >+5%、盘中破昨收 -3%。
- 低吸组：开盘 <-2%、收盘站不上 max(开盘, 昨收)。
- 市场级：上证 5 日跌幅闸门（≤-2.5% 强制防守）在 M 线**未启用**（引擎参数 `idx5_force_defensive=None` 保留），待样本积累后校准再启用；当前恐慌闸门为跌停 ≥30 家强制防守。

## 七、风险控制标准

### 1. 单票风险控制
- 每只标的必须带次日观察条件与风险位；未触发买点视为「观察成功、交易未触发」。

### 2. 涨停组风险控制
- 盘中 -5% / 收盘 -4% 硬离场；高开兑现区（>+5%）放弃；防范连板高度骤降日（高度 -2 且昨日 ≥5 板时 aggressive 降级）。

### 3. 非涨停组风险控制
- 盘中 -4% / 收盘 -3.5% 硬离场；T+1 缩量 <0.55 倍且收跌视为承接失败；低吸组本身期望温和（+0.69%），只适合轻仓观察仓。

### 4. 市场系统风险控制
- 恐慌跌停 ≥30 家强制防守（上证 5 日闸门保留未启用）；冰点只观察。
- 区间内最大风险来源为「市场系统性风险」（归因占比：涨停组 23/318、低吸组 16/165）与「买点未触发」（69/44 次——执行纪律问题，不是选股问题）。

## 十一、最终结论

```text
最终规则版本：M_Final（= M3，配置见 engine/rules.py M3）
总迭代轮次：3 轮（M1 → M2 → M3，上限 5 轮内收敛）
策略稳定状态：已收敛（M2 vs M3 胜率变化 0.0/+0.19pct ≤3pct，均次/回撤/兑现率无恶化，权重结构一致，轮末评审无实质修改）
涨停组策略是否有效：有效——胜率 64.5%、均次 +2.9%、盈亏比 1.79，三环境均正（normal +3.72% 最优）
非涨停组策略是否有效：弱有效——均次 +0.69% 微弱正期望，仅适合 normal/defensive 环境轻仓观察仓
该策略适合：主板 10cm 制度下的情绪周期接力与回调低吸；有盘中执行纪律（买点/风险位）的复盘驱动交易
该策略不适合：20cm/30cm 涨跌停制度标的（创业板/科创板/北交所未验证）、无买点纪律的追价执行、aggressive 环境做低吸
后续仍需观察：① 2026-09 系统性回撤样本极少（n=4），上证 5 日闸门在引擎中保留但 M 线未启用，待校准后再开启；② ≥4 板梯队上调基于 17 例小样本；③ ind_rank5 / ret20 因子梯度跨轮漂移，继续判噪声观察；④ 板块涨停=0 家的低吸桶（n=10，-1.45%）是否需要硬排除待更多样本。
```
