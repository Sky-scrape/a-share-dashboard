# UI 体检报告（2026-09-08，全站五页 + lib/）

> 纯诊断产出，作为本轮 UI 优化（令牌收敛 → 单页改造 → 图表统一 → 移动端 → 微交互）的问题基线。
> 扫描口径：硬编码颜色字面量、双主题一致性、图表规范、表格规范、断点覆盖、空数据态。

## 总体结论

工程底子好：五页全部引用 `lib/tokens.css` 单一色源，`AKTHEME.C()` 机制健全，每页都有
`akthemechange` 重绘监听，appbar 已有 ≤760px 收纳方案。问题集中在**一类**：
「纸色主题时代写死的 rgba 淡色」——底色/描边类淡色在夜台主题下不跟随 `--accent/--up/--blue`
变色，约 50 处；另有 4 处 P0 级夜台视觉错误。

## P1 — 主题不跟随（夜台下「纸色残留」，共约 45 处）

按色系归组（全部应替换为 tokens.css 新增的语义淡色 token）：

- **金/accent 淡色** `rgba(140,109,31,…)` ×20：轮动 rankrow 选中/badge.demo/对比条、竞价 tag-noise/relay-badge.lim/表头渐隐、recap ladder-b2/board-row.active/mood-warm/sp-norm、quant primary 按钮/best 行/builtin/构建表单/focus 环等。夜台 `--accent` 变青后这些仍保持纸色金。
- **红/up 描边** `rgba(180,55,44,.3~.45)` ×10：badge/错误框/relay-badge/mood/sev 行等。夜台 `--up` 是 #FF4D6D。
- **蓝/blue 淡色** `rgba(61,90,128,…)` ×6：recap glow/ladder-b1/expand-hover/mood-cold、global 渐变。
- **warn 淡色** `rgba(180,83,10,…)` ×4：recap sp-badge.near / sp-row-near。
- **中性淡色** `rgba(138,132,120,…)` ×2：recap mood-flat / sp-bj。
- **flat 描边** `rgba(138,109,46,.4)`：global mkt.lunch。
- **遮罩/弹层阴影** `rgba(30,26,18,.45)`、`rgba(33,32,28,.45)`、暖棕阴影 `rgba(40,34,20,.45)`：轮动 drill、竞价 modal——夜台应为更深遮罩 + 霓虹描边阴影。
- **页面自有变量无夜台覆盖**：recap `--glow-blue`（:21）、quant 构建表单金色辉光（:134）——机制对，但只在纸色下成立，需补 `html[data-theme="cyber"]` 覆盖。

## P1 — 一致性缺口

1. **toast 三套实现**：auction（硬编码）/ recap、quant（各自内联 var 版，样式微差）/ index、global（无 toast，静默或无反馈）。应收敛到 `lib/util.js` 一份 `AK.toast()`。
2. **表格斑马纹只有 recap 有**（`--row-alt`/`--hover-row`），其余四页表格无偶数行底色；数字列右对齐 + 等宽字体未全站贯彻。
3. **ECharts 字号散布 9–13px 无标度**；tooltip 无统一模板（背景/边框/降序）；`fontFamily` 全站未设（canvas 不认 CSS 变量，需要在 option 里显式给）。

## P2 — 打磨项

1. `--text-4` 两主题下对比度都偏低（纸 #B0AAA0/#EFEAE0 ≈ 1.9:1；夜 #47587D/#070B14 ≈ 2.2:1）——仅用于图表副标题/基准线可接受，正文禁用。
2. focus 可见性：仅 quant 有 focus 环，全站无统一 `:focus-visible` 基线。
3. 空数据态文案已覆盖（全站 59 处「暂无/无数据」），但表现不统一（有的纯文本、有的带图标），统一占位样式即可，不逐处重写。
4. 过渡动画：现状普遍无 transition，主题切换/悬停偏生硬；补 ≤150ms 的克制过渡，不加闪动动画。

## 修复策略（对应后续执行阶段）

1. tokens.css 新增一组**语义淡色 token**（soft 底 / line 描边 / scrim / 阴影 / 刻度），paper 与 cyber 各给值——CSS 侧替换即可双主题自动跟随；
2. canvas/JS 侧（P0-3/4/5）改走 `AKTHEME.alpha(AKTHEME.C().xxx, a)`，随 `akthemechange` 重绘自动换色；
3. toast 收敛进 `lib/util.js`（AK.toast），五页统一；
4. 每页逐个过：布局密度、表格规范、图表规范、窄屏、微交互；
5. 回归验收：启动服务，五页 × 亮/暗 × 桌面/375px 截图 + judge 评审。

### 验收结论（judge 评审，28 张截图）

- 桌面组：竞价/量化（双主题）、复盘（前段+9500px 长页双主题）、全球（双主题）、轮动晨报 **全部通过**——夜台无纸色残留、红涨绿跌无反色、斑马纹/辉光/热力条 token 映射正确。

### 遗留观察（不构成本轮缺陷）

1. 榜单文字红用 `--red2`（夜台 #FF7A9E）而色块/热力用 `--up`（#FF4D6D）——历史上有意为之（文字可读性），两套红并存，后续如要统一需一并核两主题对比度；
2. 竞价「高开低开分布」0%~+2% 档用 `--flat` 琥珀——平开档中性警示语义，符合本意；
3. `--text-4` 两主题对比度仍偏低（仅图表副标题/基准线使用，正文禁用即可）。
